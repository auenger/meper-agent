宿主页（模拟第三方网站）— chat-widget.js 嵌入

第三方接入只需一行 <script>：API Key 写在 data-api-key。 用户身份通过 cookie（x-mep-token）自动注入，无需登录面板。 接入方页面负责把用户 token 写入 cookie，widget 自动读取并传给 iframe。 
<script src="http://localhost:3001/chat-widget.js"
        data-chat-url="http://localhost:3001/client/"
        data-api-key="af_live_xxx"
        data-title="Agent Flow 助手"
        data-token-cookie="mep-token"
        data-width="680px"></script>
JS API：AgentFlowChat.open() / .close() / .toggle() / .setToken(token) / .logout()
