一句话定位 & 核心价值

Positioning & Value Proposition

📌 产品定位

MEPER Mind 是面向工业场景的 Agent Flow 平台，以工业 AI Agent 为核心单元，配套可视化 Flow 编排、人工节点干预、知识库与 Skills 复用、MCP 外部能力扩展、后台 Task 调度，构成完整的"感知—决策—执行—反馈"工业智能闭环。

🎯 解决的痛点

  • 工业知识散落各处：设备手册、检修 SOP、调度规则分散在文档/老员工脑中，难以沉淀复用
  • 智能化项目烟囱化：每个场景单独开发 LLM 应用，无法复用、难统一治理
  • 关键决策需要人工兜底：完全自主决策风险高，需要"人在回路"机制
  • 外部工具接入成本高：ERP / MES / SCADA / IoT 平台协议各异，对接工作繁重
  • 任务执行缺乏调度：长耗时任务无法后台异步、状态难追踪

03

功能详解

Feature Deep-Dive

AI Agent · 独立配置

每个 Agent 都是可独立调用的智能单元，通过单独的 Agent 配置页进行管理。

配置项

  • 基础信息：名称、描述、头像、分类标签
  • 模型选择：支持多家 LLM（GPT-4 / Claude / 通义 / DeepSeek 等），可独立设置 temperature、max_tokens
  • 系统提示词：富文本编辑，支持变量占位符 {{device_id}}
  • 工具绑定：可挂载 Skills、MCP 工具、知识库检索
  • 输入输出 Schema：定义 Agent 入参出参，便于 Flow 引用

典型使用

  • "设备诊断 Agent"：输入设备 ID + 报警码，输出可能原因 + 处置建议
  • "工艺优化 Agent"：输入原料参数 + 设备状态，输出最优工艺参数组合
  • "报工汇总 Agent"：输入班次记录，输出日报 + 异常清单
✅
最佳实践：单一 Agent 单一职责，避免"万能 Agent"。复杂业务通过 Flow 编排组合多个 Agent。

Agent Flow · 可视化编排

通过画布式编辑器，把多个 Agent、Skills、人工节点、条件分支组装成完整业务流程。

节点类型

  • Agent 节点：调用一个已配置的 Agent
  • Skill 节点：执行一个原子技能（如"查询设备状态"）
  • 人工节点：暂停等待人工处理
  • 条件分支：根据表达式路由不同分支
  • 并行/合并：多支路并发执行
  • 子 Flow：引用另一个 Flow 作为节点

编排能力

  • 拖拽式画布，支持缩放、连线、对齐
  • 节点间数据通过 {{node_name.output}} 引用
  • 支持版本管理、发布回滚、灰度发布

人工节点 · Human-in-the-Loop

在 Flow 中插入需要人工参与的节点，让"AI 自动 + 人工兜底"成为标配能力。

人工节点类型

  • 审批节点：审批通过/拒绝，二选一
  • 确认节点：仅需点击确认继续
  • 表单节点：填写指定字段后继续
  • 补充输入节点：Agent 主动询问后等待人工补充

通知与超时

  • 支持站内信、企业微信、钉钉、邮件通知
  • 可配置超时时间，超时自动升级或转他人
  • 所有审批操作留痕可追溯
⚠️
建议：所有"不可逆操作"（如停机、下发工单、修改参数）前必须接入人工审批节点。

知识库 · RAG 检索增强

将设备手册、SOP、历史工单、检修记录等工业文档结构化入库，为 Agent 提供"行业记忆"。

能力

  • 支持 PDF / Word / Excel / Markdown / 网页 等多格式批量上传
  • 智能切片、清洗、向量化（支持多 Embedding 模型）
  • 混合检索：向量检索 + 关键词检索 + 重排序
  • 知识库版本管理、增量更新

应用方式

  • 作为 Agent 的"知识源"，Agent 回答时自动检索
  • 在 Flow 中作为独立节点，返回检索片段

Skills · 可复用技能库

把高频原子操作封装成标准技能，跨 Agent、跨 Flow 共享。

技能类型

  • 查询类：查询设备状态、历史工单、库存
  • 写入类：创建工单、更新设备参数
  • 计算类：OEE 计算、产能预测、能耗估算
  • 集成类：调用企业内部 API、MCP 工具

技能定义

  • JSON Schema 定义入参出参
  • 支持 Python / JS 脚本后端实现
  • 权限控制：可限定特定 Agent / Flow 才可调用

MCP · 外部工具协议

基于 Model Context Protocol，把企业内外部工具服务统一接入，让 Agent 拥有"万能工具箱"。

接入方式

  • 内置 MCP Server：平台自带主流工业协议适配器（OPC-UA、Modbus、MQTT、HTTP）
  • 自定义 MCP Server：通过配置界面把任意 HTTP API 包装成 MCP 工具
  • 第三方 MCP：引入社区/合作伙伴提供的 MCP Server

典型对接

系统MCP 工具
SAP / 用友 ERPerp_query_order / erp_create_po
MES 制造执行mes_get_workorder / mes_report_qc
SCADA / DCSscada_read_tag / scada_write_setpoint
IoT 平台iot_get_telemetry / iot_list_devices

后台 Task · 异步任务调度

将耗时操作交给后台执行，释放前端，提升用户体验。

能力

  • 支持长耗时任务（小时级）后台异步运行
  • 实时进度查询、状态推送（WebSocket / SSE）
  • 失败重试、断点续跑、超时熔断
  • 任务可绑定 Agent / Flow 触发

典型场景

  • 大批量文档入库、重新向量化
  • 模型批量推理、报表生成
  • 定时巡检、定时推送
🔍
查询入口：所有 Task 在 运维中心 > 后台任务 集中管理，可按状态、时间、类型筛选。

生成并下载

STEP 4

🔑 Key 格式

采用统一前缀 + 32 位随机串，便于在日志中识别与吊销：

KEY FORMATmeper_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx # 示例（占位符，请替换为实际 Key） meper_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
🔒
安全规范：API Key 等同于密码，不得提交到代码仓库、不得在群聊明文传输、不得写入前端代码。建议使用密钥管理服务（如 Vault / KMS）注入环境变量。

架构与技术规格

Architecture & Tech Specs

🏗️ 系统架构

MEPER Mind 采用分层架构：上层为 React 单页应用（管理后台 + 终端客户端），中间为 FastAPI 应用层（同步流式 + Celery 异步 + 进程内调度），底层为可独立扩缩容的存储组件。所有服务以 Docker Compose 编排，Caddy 作为统一入口终结 TLS 并反向代理。

⚙️ 执行与调度机制

平台区分两类执行路径：Agent 对话走 同步流式（FastAPI 进程内直接运行引擎，不经 Celery），Flow / Webhook / 索引等走 异步任务（Celery 派发 + 进程内轮询调度）。

📈 性能指标（生产参考）

指标目标值备注
API P99 延迟≤ 800 ms（不含 LLM 推理）纯平台处理
Agent 单次推理≤ 8 s（P95）含 LLM 调用
Flow 并发执行≥ 500 个同时运行单集群
知识库检索≤ 200 ms（P95）百万级文档
系统可用性≥ 99.9%月度 SLA
Task 处理吞吐≥ 10,000 / 小时常规负载

🔒 安全合规

  • 传输加密：Caddy 终结全链路 TLS，对外仅暴露 HTTPS / WSS
  • 身份认证：内部用户走 JWT（access 默认 60 分钟 / refresh 7 天）+ bcrypt 密码哈希；外部 API 走 af_live_ 形式 API Key，携带 scope、资源绑定与限流
  • RBAC 权限：内置 admin / developer / operator / viewer 四角色，权限解析经 Redis 缓存、可下钻到接口级
  • 敏感字段静态加密：模型 API Key、凭据等以 AES-256-GCM 加密落库
  • 命令沙盒：Agent 产生的 shell 命令在 agent-sandbox 容器内隔离执行（network=none、只读 rootfs、内存/CPU/超时限额），失败静默降级为 subprocess 并告警
  • 审计与限额：操作留痕可追溯；会话级 Token 上限防止恶意消耗 LLM 配额
  • 私有化部署：Docker Compose 全栈可离线部署，数据不出企业内网

User Journey

不同角色在 MEPER Mind 上的典型工作路径：

管理员

平台初始搭建与日常治理

⚙️

工程师

配置 Agent、编排 Flow、交付业务
  • 需求分析：明确业务场景与输入输出
  • 配置 Agent：选择模型、写提示词、绑定工具

FAQ & 反馈渠道

Frequently Asked Questions
Q1. MEPER Mind 与 MEPER 是什么关系？

MEPER 是产品线品牌，MEPER Mind 是其下面向工业 AI Agent 的 Agent Flow 平台。两者通过 API Key 完成对接，客户端统一在 MEPER 入口访问。

Q2. 我能在没有 MEPER 客户端的情况下使用 MEPER Mind 吗？

可以。MEPER Mind 提供独立的 Web 管理后台用于配置 Agent / Flow / 知识库等，API Key 主要用于让 MEPER 客户端复用这些能力。

Q3. 一个 Flow 最长能跑多久？

单次 Task 运行时长上限默认 24 小时，可调整；如需更长请拆分或使用定时调度。

Q4. API Key 泄露了怎么办？

立即在 MEPER 客户端 设置 → API Key 管理 中吊销该 Key，并重新生成。吊销生效后所有相关调用将返回 401。

Q5. 知识库支持哪些文档格式？

支持 PDF、Word、Excel、PPT、Markdown、HTML、TXT，以及带图片的扫描件（OCR 识别）。

Q6. 数据是否出企业内网？

支持纯私有化部署。LLM 调用可配置为本地模型或内网代理，数据全程不出企业。

Q7. 如何申请新功能 / 反馈 Bug？

在内部协作平台搜索 MEPER Mind 项目，提 Issue 或联系产品经理 @mind-pm。
